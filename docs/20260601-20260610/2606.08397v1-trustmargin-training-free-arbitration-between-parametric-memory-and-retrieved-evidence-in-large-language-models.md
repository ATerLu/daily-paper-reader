## 摘要
大语言模型在回答知识密集型问题时既使用参量记忆也使用检索证据，但两种来源并非始终可靠。检索可以填补知识空白，然而分散注意力的段落可能覆盖正确的闭卷答案。我们将这种生成后的冲突研究为答案层面的来源仲裁：给定同一冻结模型的直接答案和检索增强生成答案，决定信任哪个来源。我们提出TRUSTMARGIN，一种无需训练、即插即用的仲裁层，利用模型自身的似然度对两个现有候选项进行评分。它结合了参量先验边际（测试记忆是否接受检索到的答案）和证据绑定边际（抑制仅基于段落的显著性，并衡量问题特异性的支持）。TRUSTMARGIN无需微调、外部评判或额外生成，即可在直接生成和检索增强生成之间做出选择。在2WIKIMQA和CWQA数据集上，使用三种LLaMA规模进行实验，TRUSTMARGIN始终优于直接生成和BM25检索增强生成，恢复了部分直接/检索增强生成预言机差距，并能泛化到多种无训练的检索增强生成流程中。

## Abstract
Large language models answer knowledge-intensive questions using both parametric memory and retrieved evidence, but neither source is uniformly reliable. Retrieval can fill knowledge gaps, yet distracting passages may override correct closed-book answers. We study this post-generation conflict as answer-level source arbitration: given Direct and RAG answers from the same frozen model, decide which source to trust. We propose TRUSTMARGIN, a training-free, plug-and-play arbitration layer that scores the two existing candidates with the model's own likelihoods. It combines a parametric-prior margin, which tests whether memory accepts the retrieved answer, with an evidence-binding margin, which discounts passage-only salience and measures question-specific support. TRUSTMARGIN selects between Direct and RAG without fine-tuning, external judges, or additional generation. Across 2WIKIMQA and CWQA with three LLaMA scales, TRUSTMARGIN consistently improves over Direct generation and BM25-RAG, recovers part of the Direct/RAG oracle gap, and generalizes to multiple training-free RAG pipelines.

### 1. 论文的核心问题与整体含义

*   **核心问题**：大型语言模型（LLM）在回答知识密集型问题时，面临一个关键的**源决策（Source Decision）** 问题：是信任模型自身的参量记忆（直接生成答案），还是信任外部检索到的证据（检索增强生成答案）。直接生成可能记忆过时或错误，而检索增强生成（RAG）可能引入混淆或无关的段落，覆盖原本正确的闭卷答案。
*   **整体含义**：论文指出，直接生成与RAG答案之间存在显著的互补性，一个固定的源策略（例如总是使用RAG）是脆弱的。因此，核心挑战并非全局性地选择哪个来源更好，而是在**实例级别**决定何时应让检索到的证据覆盖参量记忆。本研究将这个问题定义为**答案层面的源仲裁（Answer-Level Source Arbitration）**。

### 2. 论文提出的方法论

*   **核心思想**：提出 TRUSTMARGIN，一个**无需训练、即插即用**的仲裁层。其核心是在不修改模型、不训练额外判断器、不产生第三个答案的前提下，从已有的直接生成答案 \(y_D\) 和检索增强生成答案 \(y_R\) 中做出选择。
*   **关键技术细节（M-生成器）**：仲裁决策基于一个名为 **M-生成器** 的组件，它利用冻结模型的似然度对两个候选答案进行评分，包含两个互补的边界（Margin）：
    *   **参量先验边界（Parametric-Prior Margin, \(M_{prior}\)）**：作为**记忆侧的护栏（Memory-Side Guardrail）**。它计算在仅有问题的条件下，模型认为检索增强生成答案 \(y_R\) 比直接生成答案 \(y_D\) 更可信的程度。公式为 \(M_{prior} = \ell_D(y_R) - \ell_D(y_D)\)。若该值为强负数，表示模型记忆强烈偏好直接答案，不应被检索结果覆盖。
    *   **证据绑定边界（Evidence-Binding Margin, \(M_{bind}\)）**：旨在识别**问题特异性的证据支持**，而非单纯的段落显著性。它首先计算问题-上下文联合支持与仅上下文支持的差值 \(\Delta(y) = \ell_R(y) - \ell_C(y)\)，然后比较两个候选答案的差值，\(M_{bind} = \Delta(y_R) - \Delta(y_D)\)。正值表示检索增强生成答案从问题与证据的交互中获得了更多支持。
*   **最终决策**：总信任分数 \(M = M_{prior} + \lambda_{bind} M_{bind}\)。当且仅当 \(M > \tau\) 时，接受检索增强生成答案 \(y_R\)，否则保留直接生成答案 \(y_D\)。实验中固定 \(\lambda_{bind}=0.5\) 和保守阈值 \(\tau=-1.5\)。

### 6. 论文的主要结论与发现

*   **性能提升**：TRUSTMARGIN在所有模型规模和数据集上，**一致地提升了**平均F1和精确匹配（EM）分数，优于直接生成和BM25-RAG基线。

*   **鲁棒性**：面对检索噪声（如混入随机段落），TRUSTMARGIN的**检索增强生成选择率会自动降低**，证明其能有效感知证据质量并回溯到参量记忆。
*   **通用性**：该方法可作为**插件式仲裁层**，用于改善多种无训练检索增强生成流程的表现，只要直接生成和检索增强生成候选答案之间存在有益的差异。

### 7. 优点

*   **无需训练，即插即用**：方法完全基于冻结模型的似然分数，无需任何微调、额外模型或人工标注，可直接部署到现有的直接生成和检索增强生成系统之上。
*   **可解释性强**：决策过程清晰可审计，由两个具有明确物理意义的边界（记忆护栏、证据绑定）决定，而非一个黑盒判断器。
*   **问题定义新颖**：将源可靠性问题从“是否检索”前推到生成后的“答案级仲裁”，是对现有自适应检索方法的重要补充。
*   **实验扎实全面**：涵盖了多规模模型、多数据集、多维度的诊断分析和泛化性测试，论证充分。

### 8. 不足与局限

*   **候选集受限**：方法本质上受限于已有候选答案集的质量。它只能在两个现有答案中选择，**当直接生成和检索增强生成答案均错误时，方法将无法提供正确答案**。
*   **延迟开销**：虽然无需训练，但推理时仍需额外生成和评分计算。其在线延迟高于单次生成方法，可能限制其在极低延迟要求场景下的应用。
*   **多样性依赖**：方法的增益来源于直接生成和检索增强生成候选答案之间的互补性。当两者高度相似或RAG未能提供有效多样化答案时（如与FLARE结合时的接近中性结果），仲裁的作用有限。
