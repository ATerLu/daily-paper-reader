## 摘要
本文介绍了我们在第二届多模态检索增强的多模态增强生成研讨会（MAGMaR）上的系统描述。针对跨语言长视频理解、严格遵循人物角色设定以及零幻觉时间定位等关键挑战，我们提出了一种完全无需训练的、级联的两阶段视频RAG流水线。我们的架构通过模态感知的劳动分工，战略性地将语义检索与认知逻辑推理解耦。在第一阶段，一个高召回率的语义预取模块仅使用高保真的视觉摘要和全局文本描述进行稠密检索，明确隔离噪声模态（如OCR和ASR），以保持纯净的向量空间。在第二阶段，一个由商用大型语言模型（LLM）驱动的自适应、迭代和基于推理（A.I.R.）的过滤代理执行细粒度的认知重排序。该代理重新整合全模态上下文，以强制与用户角色设定严格逻辑对齐，有效修剪语义相似但逻辑无关的候选项。最后，一个提示塑造机制约束生成器将提炼后的子集合成为严格格式化的JSON响应，并带有精确的片段级引用。在RAG赛道的评估中，我们这种资源感知的方法在信息检索和角色条件生成两方面都表现出卓越的精确度。

## Abstract
This paper presents our system description for the 2nd Workshop on Multimodal Augmented Generation via MultimodAl Retrieval (MAGMaR). Addressing the critical challenges of cross-lingual long-video comprehension, strict persona adherence, and zero-hallucination temporal grounding, we propose a fully training-free, two-stage cascaded Video RAG pipeline. Our architecture strategically decouples semantic retrieval from cognitive logical reasoning through a modality-aware division of labor. In the first stage, a high-recall semantic pre-fetching module employs dense retrieval using only high-fidelity visual summaries and global text descriptions, explicitly isolating noisy modalities (e.g., OCR and ASR) to maintain a pristine vector space. In the second stage, an Adaptive, Iterative, and Reasoning-based (A.I.R.) filtering agent, powered by a commercial Large Language Model (LLM), performs fine-grained cognitive reranking. The agent re-incorporates full multimodal contexts to enforce strict logical alignment with user personas, effectively pruning semantically similar but logically irrelevant candidates. Finally, a Prompt Sculpting mechanism constrains the generator to synthesize the distilled subset into strictly formatted JSON responses with exact chunk-level citations. Evaluated on the RAG track, our resource-aware approach shows exceptional precision in both information retrieval and persona-conditioned generation.

### 2. 论文提出的方法论
- **核心思想**：采用“粗到精”的级联架构，将表面语义匹配（粗阶段）与深层认知推理（细阶段）明确分离，降低噪声并提升逻辑一致性。
- **关键技术细节**：
  - **粗阶段：高召回语义预取**
    - 模态解耦：仅使用全局视觉摘要（由 Qwen‑Omni 生成）和关键帧描述，排除 OCR/ASR 等噪声模态，保持向量空间高信噪比。
    - 稠密检索：用多语言长文本嵌入模型 BGE‑M3（最大长度 8192 token）将视频库索引到 Qdrant 向量数据库，通过余弦相似度检索 Top‑1000 候选。
  - **细阶段：认知重排序**
    - 序列化多模态上下文（SMC）：将候选视频的全局摘要、帧细节、对齐的 OCR 和 ASR 转录拼接成时间有序的统一文本，供 LLM 统一推理。
    - 自适应、迭代、基于推理的过滤代理（A.I.R.）：
      - **自适应**：根据查询复杂度动态调整模态粒度，复杂需求优先高熵模态（OCR/ASR）。
      - **迭代**：将 1000 候选分批（如 20 个一批）评估，逐步填充 10‑15 个“黄金子集”。
      - **推理**：用“证据链”提示，评估每个视频与角色和查询的逻辑对齐，显式拒斥硬负例。
    - 逻辑门控指数衰减（LGEA）评分校准：\(S_{\text{final}}(v) = s_{\text{coarse}}(v) \cdot \exp(-\gamma \cdot (1 - L(v)))\)，当逻辑对齐度 \(L(v)=1\) 时语义分完全保留，\(L(v)=0\) 时分值被指数压制，通过超参数 \(\gamma\) 平衡推理严格性与语义保真度。
  - **生成阶段**：
    - 提示塑造（Prompt Sculpting）：强制 LLM 采用指定角色、忽略不满足证据阈值的候选、禁止注入外部知识。
    - 块级时间定位：利用 SMC 中的时间戳，要求生成器将每个事实声明锚定到具体时间区间 `[start_time, end_time]`。
    - 确定性模式执行：定义严格 JSON Schema，并用后处理层校正格式偏差，确保 100% 合规输出。

### 7. 优点
- **训练无关**：完全无需微调，即插即用，降低部署门槛。
- **解耦设计**：清晰分离语义检索与逻辑推理，有效缓解硬负例干扰，提升检索精确度。
- **逻辑门控评分（LGEA）**：指数衰减公式为融合语义相似度和逻辑一致性提供了数学上严密、可调的“软硬边界”。
- **多模态序列化与代理分工**：SMC 统一不同模态的时间轴，A.I.R. 代理实现自适应、迭代、证据链推理，过滤能力强。
- **零幻觉强约束**：生成阶段通过提示严格控制知识边界和引用格式，结合确定性后处理，保证了输出合规性和可审计性。
- **资源效率**：依赖商用 LLM API 却能在分钟内完成万量级候选的重排序，实用性强。
