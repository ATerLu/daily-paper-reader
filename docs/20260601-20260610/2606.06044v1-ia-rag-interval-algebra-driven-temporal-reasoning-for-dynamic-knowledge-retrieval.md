## 摘要
检索增强生成（RAG）在将大型语言模型（LLM）与外部知识相结合方面表现出强大的有效性。然而，现有的RAG和图RAG框架大多将知识视为静态的，或将时间与粗粒度的时标或元数据关联，未能捕捉到丰富的时间结构，如持续时间、重叠和包含关系。我们提出IA-RAG，一个分层的时间RAG框架，将知识建模为时间区间，并在形式化的时间约束下进行检索。IA-RAG将事实表示为区间事件单元（IEU），并将其组织成层次化的主题森林，其中时间依赖关系由Allen区间代数控制。为了处理不完整或不确定的时间边界，IA-RAG进一步引入子图时间收紧机制，通过连接事件子图中的逻辑约束来细化模糊区间。此外，IA-RAG通过区间代数引导的遍历支持隐式时间语义检索。在多个时间问答基准（包括TimeQA、TempReason和ComplexTR）上的实验表明，IA-RAG实现了强大的时间检索和推理性能，特别是在复杂的组合时间推理任务上。我们的代码发布在https://github.com/xiaoAugenstern/LogicalRAG_TemporalQA。

## Abstract
Retrieval-Augmented Generation (RAG) has shown strong effectiveness in grounding Large Language Models (LLMs) with external knowledge. However, existing RAG and Graph RAG frameworks largely treat knowledge as static or associate time with coarse-grained timestamps or metadata, failing to capture rich temporal structures such as duration, overlap, and containment. We propose IA-RAG, a hierarchical temporal RAG framework that models knowledge as time intervals and performs retrieval under formal temporal constraints. IA-RAG represents facts as Interval Event Units (IEUs) and organizes them into a hierarchical Thematic Forest, where temporal dependencies are governed by Allen's Interval Algebra. To handle incomplete or uncertain temporal boundaries, IA-RAG further introduces a Sub-graph Time Tightening mechanism that refines fuzzy intervals through logical constraints within connected event subgraphs. In addition, IA-RAG supports implicit temporal semantic retrieval through interval-algebra-guided traversal. Experiments on multiple temporal question answering benchmarks, including TimeQA, TempReason, and ComplexTR, demonstrate that IA-RAG achieves strong temporal retrieval and reasoning performance, particularly on complex compositional temporal reasoning tasks. Our code is released at https://github.com/xiaoAugenstern/LogicalRAG_TemporalQA.

## 1. 论文的核心问题与整体含义
- **研究背景**：检索增强生成（RAG）和图 RAG 方法通过外部知识库提升了 LLM 的事实可靠性，但现有框架将时间视为静态元数据或离散时间戳，难以处理真实世界中事件的时间跨度、重叠、包含等拓扑关系。
- **核心问题**：传统 RAG 无法有效进行复杂时间推理，具体表现为三点：
  - **时间边界模糊**：语义检索难以区分同一主体在不同时期的状态。
  - **隐含时间属性无法细化**：许多事实缺乏明确时间戳，无法利用事件间关系来推断缺失的时间区间。
  - **拓扑推理缺失**：复杂查询需判断事件是否发生在另一事件期间等关系，现有系统只能依赖脆弱的语言推理，而非结构化时间逻辑。
- **整体含义**：提出 IA-RAG，利用 Allen 区间代数对事件进行严格建模与推理，以支持动态知识检索中的精细时间推理。

## 2. 论文提出的方法论
- **核心思想**：将知识表示为由 Allen 区间代数约束的时间区间（Interval Event Unit, IEU），并组织为层次化主题森林，实现带时间约束的检索与推理。
- **关键技术细节**：
  - **IEU 提取与定义**：
    - 公式：\( e_i = \langle s_i, c_i, [t^{start}_i, t^{end}_i], f_i, src_i \rangle \)，其中 \(s_i\) 为事件句子，\(c_i\) 为上下文，时间区间可显式或模糊（\(f_i=1\)）。
    - 对文档进行滑动窗口分块后提取 IEUs，并通过语义相似度去重。
  - **区间感知事件图构建**：
    - 基于语义相似度阈值 \(\tau_{sem}\) 筛选相关 IEU 对。
    - 应用 Allen 的 13 种基本区间关系（如 before、overlaps、during 等）定义边的类型。
  - **子图时间收紧**：
    - 针对模糊边界（\(f=1\)）的 IEU，在所在连通分量内利用相邻事件的精确时间区间和 Allen 关系，通过 LLM 推理收紧时间边界，并可能将模糊标志更新为 \(f=0\)。
  - **宏事件单元与主题森林**：
    - 在连通分量基础上聚合生成宏事件单元（MEU），递归构建多层事件图，形成层次化主题森林。
    - 高层单元与低层单元间存在包含关系，构成从细节到主题的树状结构。
  - **查询驱动的事件检索**：
    - LLM 解析查询得到时间窗口 \(T_w = [w_s, w_e]\)。
    - 从主题森林中分别检索相关的 top-\(K_1\) MEUs 和 top-\(K_2\) IEUs。
    - **区间代数引导的遍历**：根据检索到的单元与查询窗口的相对位置，动态选择前向（before、meets 等）或后向关系集（after、met_by 等）进行图遍历，补充时间相关的相邻节点。
- **算法流程**：整体框架分为三个阶段：IEU 提取、区间感知事件图构建（包括时间收紧和层次化）、查询驱动的分层检索与遍历。
