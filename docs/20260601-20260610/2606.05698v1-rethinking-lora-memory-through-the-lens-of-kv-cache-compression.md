## 摘要
参数化检索增强将文档信息编码为轻量级、文档特定的模块，如LoRA适配器，从而减少了将所有证据作为输入上下文的需要。然而，这种参数侧的记忆如何与存储在KV缓存中的上下文侧记忆相互作用仍不清楚。我们通过在文档级问答中逐步驱逐文档键值状态，并测量文档LoRA何时在保留的上下文之外做出贡献，来研究这种相互作用。我们发现，当KV缓存基本完整时，文档LoRA贡献甚微，但在激进压缩下变得日益有用，在没有文档上下文保留时，恢复了13-21个ROUGE-L点。当基座模型编码文档，且适配器仅在答案生成期间应用时，增益最大，这表明文档LoRA更适合理解为解码时的参数化记忆，而非文档编码器。最后，问答风格的监督产生了比原始上下文的下一个词预测强得多的适配器。这些结果表明，文档LoRA作为一种补充记忆通道，其价值恰好在上下文侧证据稀缺时显现。

## Abstract
Parametric retrieval augmentation encodes document information into lightweight, document-specific modules such as LoRA adapters, reducing the need to include all evidence as input context. However, it remains unclear how this parameter-side memory interacts with context-side memory stored in the KV cache. We study this interaction in document-level question answering by progressively evicting document key-value states and measuring when a document LoRA contributes beyond the retained context. We find that document LoRA adds little when the KV cache is largely intact, but becomes increasingly useful under aggressive compression, recovering 13-21 ROUGE-L points when no document context remains. The gain is largest when the base model encodes the document, and the adapter is applied only during answer generation, suggesting that document LoRA is better understood as decoding-time parametric memory than as a document encoder. Finally, QA-style supervision produces substantially stronger adapters than raw-context next-token-prediction. These results position document LoRA as a complementary memory channel whose value emerges precisely when context-side evidence is scarce.

### 6. 论文的主要结论与发现

1.  **LoRA补充高压缩场景**：文档LoRA并非通用的长上下文替代品，其价值在**KV缓存被极度压缩（如99%以上）或完全清空**时最为显著，此时可恢复13-21个ROUGE-L点。当缓存保留充分证据时，LoRA增益甚微。
2.  **LoRA的最佳角色是解码器**：将文档LoRA应用于**解码阶段**比应用于**文档编码阶段**更有效。最强组合是用基座模型完成文档预填充和压缩评分，只在答案生成时激活LoRA适配器。这表明LoRA更适合作为**生成时的参数化记忆支撑**，而非文档编码器。
3.  **QA风格监督至关重要**：仅靠“背诵”文档文本（Raw NTP）训练的LoRA在问答任务上表现很差。**合成QA对风格的监督信号**是产生有效适配器的关键，它迫使适配器学习从问题到答案的映射关系，以便在缺乏上下文时能够“回忆”和表达。

### 7. 优点

-   **新颖的交互视角**：首次系统性地研究了参数侧记忆（文档LoRA）与上下文侧记忆（压缩后的KV缓存）的互补关系，将两个此前隔离的研究方向联系起来。
-   **诊断框架清晰**：提出的“渐进压缩-阶段分离-格式对比”三位一体诊断框架逻辑清晰，能够有效剥离不同因素的贡献，为理解LoRA的工作机制提供了有力工具。
-   **结论指导性强**：研究结论直接指向一种切实可行的最佳实践：**“基座模型预填充 + 适配器增强解码”**，这对于在紧凑KV缓存预算下构建高效的LLM服务系统具有直接的指导价值。
-   **实验稳健扎实**：结论在多个模型、数据集以及不同压缩算法上得到了一致验证，增强了结论的普适性和说服力。

### 8. 不足与局限

-   **系统构建不完整**：研究定位为诊断性分析，未构建一个包含适配器检索、路由、多文档聚合和存储加载策略的完整服务系统。评估假设了正确的文档适配器已知且可用。
-   **任务与领域有限**：实验仅限于长文档问答任务，且NarrativeQA和LongHealth两个数据集均为英文。结论在更广泛的文本生成、摘要或多语言场景下的适用性有待验证。
-   **单一压缩算法**：尽管消融实验比较了两种压缩算法，但整体研究框架依赖于KV缓存压缩这一特定手段。其他上下文预算控制方式（如检索截断）下的交互模式可能有所不同。
-   **适配器容量固定**：研究未深入探讨LoRA的秩（rank）等关键容量超参数如何影响其在高压缩下的表现，默认配置可能并非最优。
