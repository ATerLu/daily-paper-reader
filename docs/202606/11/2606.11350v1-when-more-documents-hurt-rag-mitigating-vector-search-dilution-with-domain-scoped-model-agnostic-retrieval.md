## 摘要
检索增强生成在扩展到大规模异构文档集合时会退化，其中密集相似性失去区分能力，top-k 检索越来越多地返回语义相似但上下文不正确的文本块。我们将这种失效模式称为向量搜索稀释。即使在混合使用密集+稀疏检索的情况下，我们在一个部署的怀俄明州交通部语料库中亲身观察到了这一点，当规模从 54 篇文档扩展到 1128 篇文档（88907 个文本块）时，准确率从 75% 下降到低于 40%。为了解决这种稀释，我们提出了 MASDR-RAG（面向 RAG 的多智能体领域限定检索），并在五个 LLM 骨干、六个语料库和两个索引堆栈上，针对 200 个经专家验证的查询进行了评估。结果表明，利用组织元数据进行领域限定是关键修复方法，将 P@10 从 0.77 显著提高到 0.86（$p < 0.05$）。此外，我们对多智能体编排的研究发现，高度依赖于配置的结果——产生了我们称之为精度-忠实度悖论的现象。基于这些不同结果，我们的实用建议很简单：首先进行领域限定，然后执行单次合成调用，将完整的多智能体编排保留给真正的多领域语料库并配合原生工具调用骨干。代码和数据将在接收后公开。

## Abstract
Retrieval-augmented generation degrades when scaled to large, heterogeneous document collections, where dense similarity loses discriminative power, and top-k retrieval increasingly returns semantically similar but contextually incorrect chunks. We refer to this failure mode as vector search dilution. Even when using hybrid dense+sparse retrieval, we observed this firsthand in a deployed Wyoming Department of Transportation corpus, where scaling from 54 to 1,128 documents (88,907 chunks) reduced accuracy from 75% to below 40%. To address this dilution, we propose MASDR-RAG ( Multi-Agent Scoped Domain Retrieval for RAG) and evaluate it on 200 expert-validated queries across five LLM backbones, six corpora, and two index stacks. Our results indicate that domain scoping using organizational metadata is the key fix, significantly improving P@10 from 0.77 to 0.86 ($p < 0.05$). Furthermore, our investigation of multi-agent orchestration revealed that a high degree of configuration dependence results --creating what we call the precision-faithfulness paradox. Based on these varied outcomes, our practical recommendation is simple: scope first, then perform a single synthesis call, reserving full multi-agent orchestration for genuinely multi-domain corpora paired with native-tool-call backbones. Code and Data will be made public upon acceptance.

## 论文总结

### 1. 核心问题与整体含义  
- **研究动机**：检索增强生成（RAG）在面向大规模、异构文档集时，密集检索会失去判别力，top-k 结果经常语义相关但上下文错误。作者将这一失效模式定义为 **向量搜索稀释**。  
- **现实案例**：怀俄明州交通部（WYDOT）的实际系统中，文档量从 54 篇增至 1128 篇（约 8.9 万 chunk），准确率从 75% 降至 40% 以下。  
- **核心问题**：如何在大规模、多领域企业语料中缓解向量搜索稀释，恢复检索精度，同时避免多智能体协作带来的“精确度–忠实度悖论”。

### 2. 方法论  
- **核心思想**：利用文档图谱中已有的组织元数据（如 `document_series`、`source_type`）对检索空间进行**领域限定（domain scoping）**，将查询路由到对应的领域索引中搜索，大幅缩小有效检索空间（减少 85%–98%）。  
- **架构**：提出 **MASDR-RAG**（多智能体限定域检索）和轻量变体 **HYBRID-ROUTED**。  
  - **混合路由**：先用正则表达式快速匹配领域，失败时再由 LLM 零样本分类路由。  
  - **多智能体编排**：一个推理 agent 拥有 K 个领域限定工具，通过函数调用在限定域内检索；每次检索仅在对应 agent 的元数据过滤范围内执行 ANN 搜索。  
- **关键公式**：稀释因子 δ 定义为全局检索精度与领域限定精度之差的比例，δ 越大表示稀释越严重。实验中观察到低 chunk 密度的类别（如设计手册）稀释最严重（δ=0.53），高密度类别（如施工手册）几乎不受影响。  
- **重要变体**：  
  - **HYBRID-ROUTED**：路由 + 单次合成调用，仅需至多两次 LLM 调用。  
  - **R2-ROUTED**：训练基于 BGE-M3 查询嵌入的逻辑回归路由器，进一步提高路由准确率。

### 3. 实验设计  
- **数据集/场景**：  
  - 主测试集：WYDOT 200 条专家验证的查询（覆盖单域、跨域、版本比较等）。  
  - 泛化测试：EnterpriseComposite-9（9 种公开数据源合并）、HotpotQA-distractor、MultiHop-RAG、NQ-Open、FinanceBench、MMLU-Pro。  
  - 跨组织复制：California（Caltrans）和 Colorado（CDOT）交通部语料。  
- **对比方法**：Monolithic（全库检索）、Mono+RRF（混合检索）、LLM+Scoped（仅 LLM 路由 + 限定域）、MASDR-RAG、HYBRID-ROUTED、Custom ReAct、LangChain ReAct、MA-RAG、SCOUT-RAG，以及 BM25、ColBERTv2、SPLADE 等检索器基线。  
- **评估指标**：P@10、R@10（目标领域内的 chunk 精度/召回）、Correctness（LLM-as-judge 判断答案正确性）、Faithfulness（RAGAS 式忠实度）。  
- **骨干模型**：Qwen2.5-7B-Instruct、Llama-3-8B-Instruct、Claude-Haiku-4.5、GPT-5-mini、DeepSeek-V3。

### 4. 资源与算力  
- **生产堆栈**：使用 Gemini Embedding (768-d)，Neo4j 图数据库 + HNSW 索引。  
- **开源复制**：全部在单张 NVIDIA L40S 或 A30 GPU 上完成。  
  - 检索嵌入：BAAI/bge-m3 (1024-d)，FAISS IndexFlatIP（精确检索）或本地 Neo4j HNSW。  
  - 推理效率：Qwen-7B 完成 200 查询的全部系统评价约需 40 分钟；Llama-8B 约需 100 分钟。  
  - 总花费：约 24 GPU 小时（L40S）。  
- **训练成本极低**：路由器 R2 仅用逻辑回归在 GPU 上快速训练，推理开销可忽略。

### 5. 实验数量与充分性  
- **实验规模**：涵盖 5 个 LLM、6 个语料库、2 个索引栈，共计数十项系统对比。  
- **消融分析充分**：  
  - 路由噪音影响（正则 vs. TF-IDF vs. BGE-LR 路由器）。  
  - 领域内重排序（cross-encoder reranker）。

  - 索引实现差异（FAISS vs. Neo4j）。

  - 跨骨干信敏度（开源 vs. 商业 LLM 的行为差异）。  
- **可重复性**：提供代码和数据，给出完整的超参数和随机种子，在另一 DOT 组织语料中复现稀释现象与修复效果。  
- **客观性/公平性**：统一使用 Qwen-2.5-7B 作为评测法官，与各生成模型分离；对比方法采用相同的检索工具和提示格式。

### 6. 主要结论与发现  
- **领域限定是缓解稀释的关键**：将 P@10 从 0.77 显著提升至 0.86（p<0.05），且不受索引实现、检索器类型影响。  
- **精确度–忠实度悖论**：在生产环境中，多智能体编排 MASDR-RAG 虽然提升检索精度，却导致忠实度从 0.61 跌落至 0.35（p<0.01）。这一现象在商业 LLM（Gemini、Claude、GPT-5-mini）上复现，但在开源模型（Qwen-7B、DeepSeek-V3）上消失。  
- **实用建议**：  
  - 对于单组织/稳定领域的语料，**先限定域，再做单次合成**（如 HYBRID-ROUTED 或训练的路由器）。  
  - 仅在真正多领域、并且生成模型具有强工具调用能力时，才考虑完整的多智能体编排；否则可能得不偿失。  
  - ReAct 类循环在 Llama-8B 上代价高昂（5.9× tokens，2.2× 延迟），且未带来准确性优势。

### 7. 优点  
- **新颖的诊断形式化**：明确定义并量化了向量搜索稀释因子 δ，揭示了小类别更容易被稀释的规律。  
- **工程与学术结合**：基于真实部署环境的失败案例，提出可直接部署的修复方案，同时提供开源可复现的基准。  
- **广泛评估和多维度消融**：覆盖多种语料、检索骨架、索引实现，显著增强结论的可靠性和外部有效性。  
- **悖论的深入剖析**：不仅发现精确度–忠实度悖论，还通过系列受控消融排除了路由噪音、重排序、检索器家族等替代解释，定位到上下文碎片化和 LLM 容量，并指出与模型类型（商业 vs. 开源）的交互作用。

### 8. 不足与局限  
- **模型规模受限**：开源实验仅使用 7B–8B 参数模型，未测试 ≥70B 的大模型。  
- **LLM-as-Judge 偏差**：以 Qwen-7B 作为评判，可能对同类模型产生一定偏好，且 RAGAS 式指标假设单一上下文窗口，可能惩罚多智能体输出的忠实度分数（不过趋势在跨骨干复制中仍保持稳健）。  
- **元数据依赖性**：路由分类体系需手动设计，且依赖文档图已有组织元数据，若缺乏此类结构化信息则需要额外加工。  
- **商业模型接口封闭**：生产悖论仅在 Gemini、Claude 等商业模型上验证，可能受具体 API 行为影响，不完全代表所有商业模型。  
- **领域限定粒度**：文中推荐 3–10 个领域作为路由粒度，未详细探讨更多或更少领域划分的效果边界。
