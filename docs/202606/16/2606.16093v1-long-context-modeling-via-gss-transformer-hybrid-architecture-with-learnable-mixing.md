## 摘要
建模长程依赖仍然是自然语言处理中的核心挑战。Transformer架构通过自注意力机制实现了强大性能，但计算复杂度随序列长度呈平方增长（$O(N^2)$），而状态空间模型（SSM）虽具有线性复杂度（$O(N)$），却存在选择性回忆瓶颈，难以从压缩状态中精确检索信息。这导致了效率与困惑度之间的根本性权衡。为解决这些难题，我们提出了并行混合架构（PHA），将门控状态空间（GSS）、分组查询注意力（GQA）和前馈网络（FFN）作为独立的并行分支运行，并通过可学习的混合机制进行融合。PHA不强制状态空间去近似注意力，也不将两种范式串行化，而是让每个分支各司其职：GSS捕捉全局上下文，注意力执行选择性检索，FFN提供补充处理。在WikiText-103数据集上，PHA以1.25亿参数取得了16.51的困惑度，优于Hedgehog（16.70）和H3-125M（23.70）。扩展到1.8亿参数时，困惑度进一步降至16.42，与纯注意力基线相当，同时在长上下文场景下吞吐量提升24%，内存占用降低高达40%。在OpenWebText上，我们的1.25亿参数模型取得了19.72的困惑度，超越了标准Transformer（20.60）和GSS混合基线（19.80）。这些结果表明，将序列建模范式分解为专门的并行分支，能够在实现Transformer级别的困惑度的同时，显著提升长上下文语言建模的效率。

## Abstract
Modeling long-range dependencies remains a central challenge in natural language processing. Transformer architectures achieve strong performance via self-attention but scale quadratically ($O(N^2)$) with sequence length, while State Space Models (SSMs) scale linearly ($O(N)$) but suffer from a selective recall bottleneck, struggling to retrieve precise information from compressed states. This creates a fundamental tradeoff between efficiency and perplexity. To tackle these challenges, we propose the \textit{Parallel Hybrid Architecture (PHA)}, which runs Gated State Spaces (GSS), Grouped Query Attention (GQA), and Feed-Forward Networks (FFNs) as independent parallel branches fused by a learnable mixing mechanism. Instead of forcing SSMs to approximate attention or serializing the two paradigms, PHA allows each branch to specialize: GSS captures global context, while attention performs selective retrieval, with FFN providing complementary processing. On WikiText-103, PHA achieves 16.51 PPL at 125M parameters, outperforming Hedgehog (16.70) and H3-125M (23.70). Scaling to 180M parameters yields 16.42 PPL, which gives comparable results with the pure attention baseline while delivering 24\% higher throughput and up to 40\% lower memory usage at long contexts. On OpenWebText, our 125M model achieves 19.72 PPL, outperforming standard Transformers (20.60) and GSS hybrid baselines (19.80). These results demonstrate that separating sequence modeling paradigms into parallel specialists enables Transformer-level perplexity with substantially improved efficiency for long-context language modeling.

## 1. 研究动机与核心问题

- **长序列建模的根本矛盾**：Transformer 自注意力可建模任意距离的依赖，但复杂度为 $O(N^2)$，在长上下文场景下计算和内存开销巨大；状态空间模型（SSM）虽然达到线性复杂度 $O(N)$，却因将历史压缩到固定维度状态而存在“选择性回忆瓶颈”，难以精准回溯远距离的特定 token。
- **已有混合方案的局限**：早期混合方法（如 H3）试图让 SSM 模仿线性注意力，架构复杂；串行堆叠（如 Jamba）则可能在 SSM 层压缩信息后，造成向注意力层传递的信号瓶颈。
- **本文目标**：设计一种并行混合架构，使 SSM 和注意力各自专注（全局上下文建模 vs. 精确检索），不相互模仿，并通过可学习融合平衡效率与困惑度，实现 Transformer 级质量 + 更高效率。

## 2. 方法论：并行混合架构（PHA）

### 2.1 整体结构
- 输入经嵌入、缩放和 RMSNorm 后，并行送入三个分支：
  - **GSS 分支**：门控状态空间模型，捕捉长程依赖，更新公式 $h_t = \sigma(W_g x_t) \odot (A h_{t-1} + B x_t)$，门控 sigmoid 控制信息进入，提升并行训练稳定性。
  - **注意力分支**：采用分组查询注意力（GQA），不同规模下 query:kv 头数比 4:1 或 3:1，减少 KV 缓存；配合 Rotary Position Embedding (RoPE) 和 Scaled-Cosine Attention 稳定训练。
  - **FFN 分支**：辅助前馈网络，使用 SwiGLU 激活，与后面主 FFN 构成双 FFN 设计。
- 三路输出经 RMSNorm 归一化后，通过 **可学习静态混合** 加权求和融合。
- 融合结果再经残差连接与主 FFN（SwiGLU 扩展 2.5×）输出。

### 2.2 可学习混合机制
- 为每个分支分配可学习标量 $p \in \mathbb{R}^3$，经 Softplus 和归一化得到权重 $w_i = \frac{\mathrm{Softplus}(p_i)}{\sum_j \mathrm{Softplus}(p_j)}$。
- 融合前各分支输出独立做 RMSNorm，保证尺度一致。
- 这种方式使模型可通过梯度学习各层分支相对重要性，而非固定平均或稀疏路由。

### 2.3 稳定化技术
- 采用 DeepNorm 风格残差缩放因子 $\alpha = (2L)^{0.25}$，控制更新幅度，无需复杂预热或梯度裁剪即可稳定训练深层混合模型。

## 7. 优点与亮点

- **并行专业化设计思想**：让 SSM、注意力和 FFN 各展所长，无需相互模仿，方法新颖且简单有效。
- **简洁的可学习混合**：仅用 3 个标量 + Softplus 归一化即可实现动态分支融合，避免复杂路由或固定权重。
- **良好的性能‑效率平衡**：在达到 Transformer 级困惑度的同时，显著降低长上下文下的计算和内存开销。
- **丰富的消融与可视化**：不仅验证了组件必要性，还揭示了层间分工模式（“三明治”结构），增强可解释性。
- **稳健性验证**：多尺度、多种子、双数据集，且训练超参和稳定技术（DeepNorm、Scaled‑Cosine Attention）公开透明。

## 8. 不足与局限

- **训练资源有限**：仅在单卡 A100 上训练到 12 epoch 或 1 epoch，更大规模（B 级参数、更长训练）下的表现未知。
