## 摘要
长上下文语言建模不仅需要扩展上下文窗口，还需要在数千个token上保持对实体状态和关系的连贯理解——这一挑战仅靠语义相似性无法解决。KGERMAR通过在推理过程中从输入文本构建动态的、上下文特定的知识图谱来解决这一问题，从而利用语义相似性和显式实体关系实现领域自适应的检索。该框架执行实时实体和关系提取以构建上下文知识图谱，然后通过多组件记忆架构将图结构嵌入与文本语义相集成。三个记忆库——上下文、语义和结构——被维护，并通过学习到的权重融合检索信号，以捕获表层语义和更深层次的关系模式。在SlimPajama（84.7K训练样本）、WikiText-103（4,358样本）、PG-19（100样本）和Proof-pile（46.3K样本）上的评估表明，KGERMAR在1K到32K token的上下文长度上，与记忆增强基线相比，困惑度降低高达8.5%，记忆效率提高2-2.5倍，并在五项NLU任务中展现了卓越的上下文学习性能。动态知识图谱构建方法通过实现适应输入上下文的领域特定知识表示，而不是依赖固定知识库，推进了记忆增强语言建模。

## Abstract
Long-context language modeling requires not only extending context windows but maintaining coherent understanding of entity states and relationships across thousands of tokens -- a challenge that semantic similarity alone cannot address. KGERMAR addresses this by constructing dynamic, context-specific knowledge graphs from input text during inference, enabling domain-adaptive retrieval that leverages both semantic similarity and explicit entity relationships. The framework performs real-time entity and relation extraction to build contextual knowledge graphs, then integrates graph-structural embeddings with textual semantics through a multi-component memory architecture. Three memory banks -- contextual, semantic, and structural -- are maintained with retrieval signals fused via learned weights to capture both surface-level semantics and deeper relational patterns. Evaluated on SlimPajama (84.7K training examples), WikiText-103 (4,358 examples), PG-19 (100 examples), and Proof-pile (46.3K examples), KGERMAR achieves up to 8.5\% lower perplexity and 2--2.5x better memory efficiency than memory-augmented baselines across context lengths from 1K to 32K tokens, with superior in-context learning performance across five NLU tasks. The dynamic knowledge graph construction approach advances memory-augmented language modeling by enabling domain-specific knowledge representation that adapts to input contexts rather than relying on fixed knowledge bases.

## 1. 论文核心问题与整体含义

- **核心挑战**：长上下文语言建模的瓶颈不仅在于上下文窗口的长度，更在于如何跨数千个 token 保持对实体状态、属性及因果关系的连贯理解。纯语义相似性检索（如现有记忆增强模型）无法区分“同一实体在不同阶段的状态”或“因果相关的实体对”，导致中间信息被遗漏（lost-in-the-middle 问题）。
- **知识图谱的缺失**：现有结合知识图谱的方法依赖固定的外部知识库（如 ConceptNet），无法覆盖特定文档中动态出现的对话实体、错误代码或事务流程。
- **研究动机**：需一种能在推理时实时从输入文本中抽取实体与关系、构建动态知识图谱，并将其与语义检索相融合的框架，以在长上下文中同时捕获表层语义和深层结构化关系。

## 2. 方法论

### 2.1 整体架构（KGERMAR）
KGERMAR 包含四个紧密集成的模块：
1. **上下文知识图谱构建**：实时 NER（BERT-large，CoNLL-2003 微调）识别五类实体，关系抽取（BERT-base，TACRED 微调）在局部窗口内预测七种关系，并通过实体合并、置信度评分与过滤生成高质量图谱。
2. **图增强嵌入生成**：使用 R‑GCN 对图谱进行多跳编码，得到实体结构嵌入；再通过跨模态注意力融合文本实体嵌入（基础语言模型提取）与图嵌入，生成富含结构与语义的融合表示。
3. **多组件记忆架构**：维护三种记忆库：
   - 上下文记忆：存储中间层（第 13 层）的键值对，按 LRU 淘汰。
   - 语义记忆：基于 BGE‑M3 的稠密文本块嵌入，使用 FAISS HNSW 索引。
   - 结构记忆：存储融合后的图实体嵌入。
4. **混合检索机制**：对同一查询并行在三个库中检索 top‑K 条目，通过可学习的融合权重 λ₁、λ₂、λ₃ 综合评分，并由检索因果注意力注入到语言模型的特定上层（14, 18, 22, 26 层）。

### 2.2 关键公式述描
- **实体合并**：基于字符串相似度（≥0.85）或嵌入余弦相似度（≥0.90）合并表述变体。
- **关系权重**：\( w(h, r, t) = \alpha \cdot \text{conf}_{F_r} + (1-\alpha) \cdot \frac{\text{freq}}{\text{max freq}} \)，α=0.7，低于阈值 0.5 的三元组被滤除。
- **R‑GCN 更新**： \( \mathbf{h}_i^{(l+1)} = \sigma\left(\mathbf{W}_0^{(l)}\mathbf{h}_i^{(l)} + \sum_{r\in\mathcal{R}}\sum_{j\in\mathcal{N}_i^r} \frac{1}{|\mathcal{N}_i^r|} \mathbf{W}_r^{(l)}\mathbf{h}_j^{(l)} \right) \)
- **跨模态融合**：注意力权重 \( a_i = \text{softmax}\left( \frac{\mathbf{h}_i^{(L)}\cdot \mathbf{e}^{(i)}_{\text{text}}}{\sqrt{d_{kg}}} \right) \)，最终实体嵌入 \( \mathbf{e}_i = \mathbf{W}_{\text{fusion}}[\mathbf{h}_i^{(L)}; \mathbf{e}^{(i)}_{\text{text}}] + a_i(\mathbf{h}_i^{(L)} + \mathbf{e}^{(i)}_{\text{text}}) \)
- **多目标训练**：总损失 \( \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{LM}} + \alpha\mathcal{L}_{\text{KG}} + \beta\mathcal{L}_{\text{retrieval}} + \gamma\mathcal{L}_{\text{alignment}} \)，辅助损失包括链接预测、检索排序与跨模态对齐。

## 6. 主要结论与发现

- KGERMAR 在 3B 参数级的所有记忆增强模型中取得**最低困惑度**（WikiText‑103 上 4K 序列从 ERMAR 的 7.62 降至 7.20，16K 时 7.14 对比 7.80）。
- 在五项 NLU 任务的上下文学习中，**平均准确率最高**（4‑shot 78.6%，20‑shot 81.2%），尤其在主观性、观点极性等需要实体区分的任务上提升显著。
- **内存效率提升 2–2.5 倍**，32K 上下文时峰值内存仅 14.51 GB（ERMAR 22.87 GB），归一化每 token 内存 0.45 MB。
- 虽因实时图谱构建导致推理延迟增高（约 2 倍），但延迟增长接近线性，吞吐量下降更平缓，**可预测性更强**。

## 7. 优点

- **动态知识图谱构建**：无需预先存在的知识库，能自适应任何领域的输入文本，解决了静态图谱的覆盖面问题。
- **混合表示与多记忆架构**：首次将上下文 KV、语义稠密嵌入和结构实体嵌入融合，捕捉互补的检索信号，尤其在实体状态因果链追踪上具有优势。
- **全面的评估体系**：涵盖了百科、书籍、科学文本等不同结构化程度的数据集，同时从困惑度、ICL、内存、吞吐量多维度验证。
- **内存效率突出**：在商品级 GPU 上可处理 32K token，大幅降低部署门槛，与长序列扩展注意力模型（如 Phi3）相比内存优势明显。

## 8. 不足与局限

- **推理延迟较高**：实时图构建引入额外开销，吞吐量约为 ERMAR 的 50%～60%，实时应用需权衡。
- **关系抽取窗口受限**：仅对固定 token 窗口内的实体对预测关系，跨段落长距离关系依赖 R‑GCN 的多跳传播间接弥补，但仍可能遗漏直接因果链。
- **领域泛化风险**：NER 和 RE 模型在通用数据集（CoNLL‑2003、TACRED）上微调，对生物医学、法律等专业术语丰富的文本可能精度下降。
- **缺乏消融与敏感性分析**：未系统研究各记忆组件、融合权重、图谱构建阈值的独立影响，方法的可解释性略弱。
- **训练成本不透明**：未报告微调所用资源与时间，难以评估其训练效率。
