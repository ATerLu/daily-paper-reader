## 摘要
多模态大语言模型（MLLMs）近期展现出作为逐点重排序器的强大潜力，它们通过下一令牌预测直接建模查询-文档相关性。然而，逐点重排序面临跨查询-文档对的大量重复计算，而Transformer的因果结构仅允许通过预缓存重用前缀段。为解决现有查询优先和文档优先格式与视觉问答式提示及计算感知重用的不匹配问题，我们提出一种视觉优先的表述方式，同时提升缓存重用效率和重排序性能。但剩余成本仍然可观，主要源于三个方面：（1）模型深度——我们通过提前退出减少活跃参数；（2）跨段注意力——我们将其限制在少数几层的窄交互带内；（3）视觉令牌——我们通过嵌入引导的剪枝减少令牌数量。这些设计共同构成了miniReranker，在单查询的高重用设定下，将重排序运行时间降至密集实现的1%以下，同时保留超过96%的密集模型性能。

## Abstract
Multimodal large language models (MLLMs) have recently shown strong potential as point-wise rerankers by directly modeling query--document relevance through next-token prediction. However, point-wise reranking suffers from substantial repeated computation across query--document pairs, while the causal structure of transformers allows only prefix segments to be reused via pre-caching. To address the misalignment of existing query-first and document-first formats with both VQA-style prompting and computation-aware reuse, we propose a $\textit{vision-first}$ formulation that improves both cache reuse efficiency and reranking performance. However, the remaining cost is still considerable and stems from three main sources: (1) $\textit{model depth}$, for which we reduce active parameters via early exit; (2) $\textit{cross-segment attention}$, which we restrict to a narrow interaction band across a few layers; and (3) $\textit{visual tokens}$, where we reduce the number of tokens via embedder-guided pruning. Together, these designs form miniReranker, which reduces reranking runtime to <1% of the dense implementation under high-reuse settings for a single query, while preserving >96% of the dense model performance.

### 2. 论文提出的方法论
- **核心思想**：
  - **视觉优先序列化**：强制将视觉输入放在文本输入之前，恢复 VQA 风格提示，并基于模态组合动态调整顺序以最大化可缓存的视觉前缀。
  - **模型级冗余压缩**：通过层级 logit 探测发现重排序信号在中间层已收敛，跨段注意力集中在特定层，且大量视觉令牌对最终决策贡献微小，由此引入三项正交压缩技术。

- **关键技术细节**：
  - **视觉优先提示重构**：
    - 文本→视觉（T→V）任务：采用 `[指令, 文档, 查询]`，使视觉文档可离线预缓存。
    - 视觉→文本（V→T）任务：采用 `[指令, 查询, 文档]`，使视觉查询只编码一次并广播。
    - 视觉→视觉（V→V）任务：默认采用 `[指令, 文档, 查询]`，利用静态文档语料库的全局离线预缓存优势。
    - 理论上推导了不同顺序下在线浮点运算量（FLOPs）的精确节省量。
  - **模型级压缩三组件**：
    1.  **提前退出 (Early Exit)**：在 Transformer 的中间层（例如 Qwen3‑VL‑2B 的第 16 层）截断前向传播，直接使用该层 hidden state 经输出头计算 yes/no logit 差异得到相关性分数，跳过深层解码所需的参数。
    2.  **交互带 (Interaction Band)**：通过掩码分析发现查询-文档的有效跨段融合仅发生在少数中间层（如 2B 模型的第 8–16 层）。在非交互层屏蔽跨段注意力，使两个段独立演化；推理时只在交互带内加载第一段的 KV 缓存并计算密集的交叉注意力。
    3.  **嵌入器引导的令牌剪枝 (Embedder‑Guided Token Pruning)**：复用第一阶检索器（如 Qwen3‑VL‑Embedding）在所有层的最后一个序列令牌到各视觉令牌的注意力权重，求和后选择 top‑α% 的视觉令牌（如保留 50%），再送入重排序器，剪枝过程不引入额外前向计算。

- **视觉优先提示同时提升效果与效率**：在零样本和微调设定下，“视觉优先”格式均优于固定的查询优先或文档优先格式，且能最大化视觉前缀缓存的复用。

### 7. 亮点
- **简单且有效的视觉优先原则**：根据模态动态调整输入顺序，巧妙统一了 VQA 对齐与计算复用，无需复杂模块。
- **多维冗余联合压缩框架**：从模型深度、跨段交互和序列长度三个正交方向同时削减冗余，思路清晰，组件可拆可合。
- **零开销的令牌剪枝设计**：直接复用检索阶段嵌入器的注意力权重，不增加任何额外模型或前向计算，工程上易于部署。
- **实验全面扎实**：覆盖了图像、视频、视觉文档等多模态，测试了不同模型尺寸，提供了详细的效率曲线和消融分析，结论可靠。

### 8. 不足与局限
- **重排序范式局限**：方法专为**逐点预填式 yes/no 评分**设计，未探讨列表式重排序或需要自回归生成的代理检索系统中的适配性。
- **缓存复用高度依赖固定语料**：视觉作为文档场景下的巨大收益依赖文档语料库静态且可预缓存，对于动态更新的文档流或临时查询的视觉内容，收益会降低。
- **令牌剪枝依赖检索器质量**：剪枝效果依赖于上游嵌入器的注意力质量，若检索器本身对某些模态或数据分布表现不佳，剪枝可能丢失关键令牌。
- **硬负样本挖掘的单模型依赖**：训练数据的硬负样本仅由 Qwen3‑VL‑Embedding‑2B 挖掘，可能引入一定的模型偏差。
- 未涉及对更长、更多文档或非英语场景的深入评测，泛化性存在一定未知空间。
