## 摘要
大型语言模型（LLMs）在长上下文上的可扩展性根本上受限于标准注意力的二次复杂度，这促使人们采用具有次二次成本的线性注意力机制。为提升长上下文下的表示能力，近期方法以多状态方式组织记忆。然而，现有的多状态线性注意力方法依赖于固定的状态合并策略，无法适应动态变化的词元重要性，会不可逆地模糊关键词元，并在长序列上导致严重的误差累积。为解决这一局限，我们提出了DLA，一个面向多状态线性注意力的动态记忆建模框架。DLA引入了（i）信息感知的动态状态合并，它根据词元级别的信息变化自适应地确定状态边界，在语义转换点周围保留高分辨率表示，同时在稳定区域进行积极概括；（ii）容量有界的记忆建模，它通过选择性地合并相邻的低信息状态来维护固定大小、按时间顺序排列的状态缓存，从而在信息损失最小的情况下控制记忆增长。我们在两种不同的线性注意力模型上预训练了DLA，并在三个类别的16个数据集上进行了评估。实验结果表明，DLA相较于现有最佳方法具有优越性。

## Abstract
The scalability of Large Language Models (LLMs) to long contexts is fundamentally constrained by the quadratic complexity of standard attention, motivating the adoption of linear attention mechanisms with sub-quadratic cost. To improve representation capacity under long contexts, recent approaches organize memory in a multi-state manner. However, existing multi-state linear attention methods rely on fixed state merging policies that cannot adapt to dynamically varying token importance, irreversibly obscuring critical tokens and causing severe error accumulation over long sequences. To address this limitation, we propose DLA, a dynamic memory modeling framework for multi-state linear attention. DLA introduces (i) Information-Aware Dynamic State Merging, which adaptively determines state boundaries based on token-level information variation, preserving high-resolution representations around semantic transitions while aggressively summarizing stable regions, and (ii) Capacity-Bounded Memory Modeling, which maintains a fixed-size, chronologically ordered state cache by selectively merging adjacent low-information states to control memory growth with minimal information loss. We pre-train DLA on two different linear attention models and evaluate on 16 datasets across three categories. Experimental results demonstrate the superiority of DLA over state-of-the-art.

## 1. 论文的核心问题与整体含义
- **研究背景**：大型语言模型（LLMs）在处理长上下文时受限于标准自注意力的二次计算与内存复杂度，线性注意力（linear attention）因具有次二次复杂度而成为重要的替代方案。为进一步提高线性注意力在长序列下的表示能力，近年来多状态（multi‑state）线性注意力方法被提出，它将历史上下文划分为多个块并压缩成若干摘要状态，以降低内存和计算开销。
- **核心问题**：现有的多状态线性注意力（如 Log‑Linear Attention）依赖**固定时间表或基于规则的合并策略**，隐含假设序列信息密度均匀，无法动态适应词元（token）重要性的非均匀变化。这导致：
  - 关键语义转换点上的词元被过早吸收为粗糙摘要；
  - 合并决策不可逆，一旦合并后无法恢复个体贡献，产生严重的**误差累积**。
- **整体含义**：本文指出有效长上下文线性注意力需要**信息感知（适应表示变化）** 且**容量受控**的记忆构建机制，由此提出动态线性注意力框架 DLA。

## 2. 方法论
DLA 包含两个核心设计：

### 2.1 信息感知动态状态合并
- **动机**：固定分块策略会在语义突变区产生更大的摘要偏差（定理 3.1 给出偏差上界，推论 3.2 证明固定策略在非平稳序列上必然劣于自适应策略）。
- **关键机制**：定义**状态信息分数** \(I_t\)，衡量当前词元的状态 \(S_t\) 相对于最近记忆状态 \(S_{t-1}\) 的表示变化：
  \[
  I_t = \frac{\|S_t - S_{t-1}\|_F}{\|S_{t-1}\|_F + \epsilon}
  \]
  （实际应用中对状态进行 RMSNorm 以稳定尺度）。
- **边界决策**：推理时当 \(I_t \ge \tau\) 时触发新状态创建（\(b_t=1\)）；否则将词元并入当前状态（\(b_t=0\)）。训练时通过软门控以可微分方式学习此边界，推理时切换为硬分割。
- **效果**：在语义变化剧烈的区域（高 \(I_t\)）保持细粒度状态，在稳定区域积极合并，从而减少融合后表示异质性，最小化偏差。

### 2.2 容量有界记忆建模
- **动机**：状态数无限增长会导致不规则内存布局、可变注意力成本，不利于高效批处理推理。需将状态缓存大小显式限制为 \(K\) （文中设 \(K=30\)）。
- **机制**：
  - 维护按时间顺序排列的状态缓存 \(M=\{(S_i, n_i, \bar{I}_i)\}\)，其中 \(n_i\) 为状态包含的词元数，\(\bar{I}_i\) 为状态内累计信息分数。
  - 当缓存满（\(m=K\)）时，选择相邻状态对中**信息密度最低**的一对进行合并：
    \[
    (i^*, i^*+1) = \arg\min_i \frac{\bar{I}_i + \bar{I}_{i+1}}{n_i + n_{i+1}}
    \]
    随后执行状态加和与信息分数、计数更新，以保持缓存大小为 \(K-1\) 再插入新状态。
  - 最终输出通过在所有缓存状态上带可学习权重 \(\lambda_{t,i}\) 的线性注意力计算：
    \[
    o_t = \sum_{i=1}^m \lambda_{t,i}\, q_t^\top S_i
    \]
- **性质**：合并仅发生在相邻状态之间，保持时间顺序；选择低信息密度状态合并，最小化信息损失；状态数固定，推理成本可预测。
